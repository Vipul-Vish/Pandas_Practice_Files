# Retail Sales & Customer Analysis Using Python and Pandas

## 📌 Project Overview

This project focuses on analyzing retail sales data using Python and Pandas. The goal is to understand sales performance, profitability, customer purchasing patterns, and business trends.

The analysis helps identify profitable product categories, compare regional performance, understand customer behavior, and generate useful business insights from the data.

## 🎯 Project Objectives

- Analyze overall sales and profit performance.
- Identify the best-performing product categories.
- Compare sales and profitability across different regions.
- Analyze monthly, quarterly, and yearly sales trends.
- Identify top customers based on sales and profit.
- Examine the relationship between discounts and profit.
- Identify products and customers generating losses.
- Generate actionable business insights from the analysis.

## 📊 Dataset

**Dataset Name:** Sample Superstore Dataset

**File:** `Sample - Superstore.csv`

The dataset contains retail transaction information, including order details, customer information, product categories, sales, quantity, discounts, and profit.

## ▶️ How to Run the Project

1. Download or obtain the Sample Superstore dataset.
2. Install Python if it is not already installed.
3. Install the required libraries:

   ```bash
   pip install pandas numpy jupyter
   ```

4. Open a terminal in the project directory.
5. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

6. Open `notebooks/retail_sales_analysis.ipynb`.
7. Update the dataset path if necessary.
8. Run the notebook cells in order.
